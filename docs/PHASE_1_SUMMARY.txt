================================================================================
  USAGE SUMMARY
================================================================================

  FOR USERS:
  1. Click ⌨️ icon in chat sidebar
  2. Select connection method (HTTP recommended)
  3. Set port if needed (default 5000)
  4. Click "Start Terminal"
  5. Type messages in terminal input
  6. View responses in message log
  7. Click "Stop Terminal" when done

  FOR DEVELOPERS:
  1. Import: from chatbot.claude_terminal import get_connector
  2. Create: connector = get_connector(config, timeout=10)
  3. Connect: if connector.connect()
  4. Send: response = connector.send_message("message")
  5. Check: if connector.is_healthy()
