## Creating new plans

Use the format: `YYYY-MM-DD-short-description/`

Each plan folder should contain a `README.md` with:
- **Status**: `PLANNING` / `IN PROGRESS` / `COMPLETED` / `PARTIALLY COMPLETED` / `SKIPPED`
- Summary table of phases/features and their status
- List of files in the plan
- What's done vs. what's remaining
